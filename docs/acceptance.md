### 历史待真机验证项与切换步骤（阻塞项）

本环境无 STEPX Neo 真机与合作账号，以下能力已按文档接线并隔离在接入层，APK 装到真机后按此步骤补测：

1. **背屏实际显示**：装 APK → 开始演示局 → 手机正面朝下 → 核对点阵方向（图案按 17 列×23 行行优先设计，如方向与设计相反需在 `src/shared/egg/matrix.ts` 输出前做一次转置）、30/60 厘米可读性、裂纹与问号可区分。
2. **最小调用验证**：在真机 console 或探针页执行 `window.mcp.connect()` 后 `callTool('set_back_screen_frame', {frame: new Array(391).fill(255)})`，确认全亮、再 `clear_back_screen_frame` 确认释放；记录系统是否抢占及恢复行为。
3. **到期短振**：前台到期 `vibrateShort` 可感知性；切后台后是否执行。
4. **翻面自动揭晓**：真机读 `getSensor` 三轴，确认正面朝下/朝上阈值（当前 z < -5 视为朝下、z > +5 视为朝上），通过后在 `src/shared/egg/types.ts` 将 `flipReveal` 默认值改 `true`（HatchPage 开关文案同步去掉「实验功能」标注）。
5. **锁屏 / 切应用 / 接电话恢复**：桌面模式保持亮屏是否生效、到期 30 秒释放、回前台阶段一致。
6. **系统读屏**： TalkBack / 旁白下走完开始→孵化→揭晓，确认阶段文本播报不刷屏、结果可读。
7. **现场可读性试玩**：按 PRD 03/07 章，30cm 与 60cm 各观察，4 名试用者至少 3 名能指出完整蛋/裂纹蛋/问号三种状态。
